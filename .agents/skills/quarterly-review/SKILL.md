# Quarterly Review

## 参照
`docs/quarterly/`、対象3か月の`docs/monthly/`、`SECURITY_INTELLIGENCE_SELECTION_POLICY.md`、元記事・根拠。

## 手順
1. 四半期と対象日付範囲を確定し、事案発生日、記事更新日、編集確定日を分離する。
2. 月次Core Themesと原資料を読み、単純な合算・転載ではなく、共通点と変化点を見つける。
3. 攻撃、Identity Trust、AI、Supply Chain、規制、復旧、ガバナンス等のうち、根拠がある構造変化を絞る。
4. 前四半期との差、重要性、経営判断、実務上の対策と次期に観測すべき指標を示す。
5. 確認事実・情報源の観測・Libraryの分析を明確に分け、一次情報と留保を追跡可能にする。
6. 既存四半期フォーマットに従って草稿とテーマの採否理由をまとめる。
7. 編集担当者が確認するまではFinal・公開扱いにしない。

## 禁止
月次の順位を四半期の順位に機械転用しない。推論や将来予測を確認済み事実にしない。

## 成果
四半期横断分析ドラフト、構造変化の比較、根拠、未解決点と承認表。
