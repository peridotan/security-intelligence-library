# Contributing

Security Intelligence Library is a curated editorial site.

## Editorial Content

External pull requests that add or substantially rewrite editorial articles are
**not accepted by default**. This avoids unclear copyright ownership and
editorial responsibility.

For factual corrections, broken links, source suggestions, or topic ideas,
please open a GitHub Issue. Do not include confidential, personal, customer,
NDA-covered, credential, or other sensitive information.

## Software Contributions

Code, workflow, stylesheet, or configuration contributions may be considered.
By submitting a software contribution, you agree that your contribution may be
distributed under the repository's MIT software license (`LICENSE-CODE.txt`).

## Security Issues

Do not disclose secrets, credentials, or sensitive vulnerability details in a
public Issue. See `.github/SECURITY.md`.
