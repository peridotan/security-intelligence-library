# Identity Security

<div class="sil-category-intro" markdown>

MFA、Passkey、PAM、IGA、ITDR、Non-Human Identity（NHI）、AI Agent Identityなど、**人・端末・ワークロード・AI AgentのIdentity**を横断して扱います。

</div>

## Focus Areas

<div class="grid cards" markdown>

-   **Passkey / FIDO**

    フィッシング耐性、同期パスキー、端末侵害、回復フローを含む認証設計。

-   **PAM / PIM / ITDR**

    特権アクセスとIdentity Threat Detection & Responseを統合した防御。

-   **NHI / AI Agent Identity**

    サービスアカウント、Workload Identity、AI Agentの委任・最小権限・監査。

-   **Recovery / Helpdesk**

    強固な認証を迂回させないアカウント回復とヘルプデスク本人確認。

</div>
