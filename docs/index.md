## How to use this library

- **横断検索** — 右上の検索からテーマ、製品名、技術用語を検索
- **月次で振り返る** — Monthly Intelligenceで「その月に何が重要だったか」を確認
- **カテゴリ / Topicから探索** — 分野別・論点別に関連記事をたどる
- **記事を原本として再利用** — 必要に応じてPowerPointや説明資料へ再構成
- **公開情報専用** — 顧客情報、社内限定情報、NDA対象情報、秘密情報は掲載しない

詳しい編集・情報管理方針は [About / Editorial Policy](about/index.md) を参照してください。
