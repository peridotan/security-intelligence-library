# August 2026 Intelligence

<div class="sil-executive-summary" markdown>

## Executive Summary

2026年8月の大きな変化は、**攻撃者側の時間軸が短くなり、IdentityとAI Agentが新しい操作主体・攻撃面として前面に出たこと**です。同時に、AIのCyber能力やAI Enabled Malwareを過度に煽らず、観測データと確認済み事実で評価する必要性も高まりました。

経営の観点では、①高リスク露出を何時間残すか、②HumanだけでなくAgent/NHIの権限をどう統制するか、③OT・重要インフラまで含めた事業継続をどう守るか、④EU AI Actや日本の重要インフラ基準を運用・証跡へどう落とすか、が主要論点です。

</div>

## 今月の5つの構造変化

| 構造変化 | 経営上の意味 |
| --- | --- |
| Exploitation Windowの短縮 | パッチ件数より「高リスク状態の残存時間」を管理する |
| Identity中心の侵入 | MFAだけでなくPasskey、ITDR、回復、NHIまで統合する |
| Agentic AIの権限拡大 | Sandbox、短命Credential、監視、停止手段を設計する |
| CyberとOT/Physicalの接近 | IT IncidentとSafety / BCPを分離しない |
| AI規制の実装フェーズ化 | Inventory、Role、Control、Evidenceを運用へ組み込む |

## Management View

この10テーマを個別ニュースとして扱うのではなく、次の4つの経営問いへ集約すると判断しやすくなります。

1. **攻撃可能な状態をどれだけ長く残しているか**
2. **人・Agent・NHIの権限と行為を追跡できるか**
3. **IT障害がOT・Safety・事業停止へ波及した時に復旧できるか**
4. **規制要求をInventory・Role・Control・Evidenceへ変換できているか**
