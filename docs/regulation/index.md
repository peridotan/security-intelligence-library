# Regulation

<div class="sil-category-intro" markdown>

サイバーセキュリティ、AI、データ保護、重要インフラ等に関する国内外の規制・政策・ガイドラインを、**要求事項だけでなく経営・実務への影響**まで整理します。

</div>

## Coverage

<div class="grid cards" markdown>

-   **Japan**

    国内法令、政府方針、監督指針、業界ガイドライン。

-   **European Union**

    AI、サイバー、データ保護、製品セキュリティ関連規制。

-   **United States**

    NIST、連邦機関、規制当局、州レベルの主要動向。

-   **International Standards**

    ISO/IEC、ETSI等の標準・ベストプラクティス。

</div>
